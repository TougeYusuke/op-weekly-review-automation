## 🎯 機能

- 週次データの自動集計（記事数、収益、作業時間）
- 週次レビュー用レポートの自動生成
- 来週の計画テンプレートの自動生成
- 累計収益の自動計算
- 目標までの残り金額の自動計算

---

## 💡 背景・課題

**なぜこのプロジェクトを作ったか:**
- 週次レビューに3時間かかっている
- 手動でデータを集計するのが面倒
- 来週の計画テンプレートを毎回手動で作成している

**改善前の状況:**
- Before: 週次レビューに3時間かかっていた
- After: 週次レビューの時間を50%削減（3時間 → 1.5時間）を目指す

## 🚀 使い方

1. **スプレッドシートのセットアップ**
   - テンプレートスプレッドシートを作成
   - GASコードをコピー＆ペースト

2. **日次データの入力**
   - 毎日、日次データ入力シートにデータを入力

3. **週次レビューの実行**
   - 金曜日にGAS関数を実行
   - レポートシートと来週の計画シートを確認

詳細は [[開発仕様書|開発仕様書.md]] を参照してください。
