# 📐 開発仕様書

**プロジェクト名:** 週次レビュー自動化ツール  
**最終更新:** 2026-01-02

---

## 🎯 プロジェクト概要

Operation Phoenixの週次レビュー（金曜日の作業）を自動化するツールです。

**解決する課題:**
- 週次レビューに3時間かかっている
- 手動でデータを集計するのが面倒
- 来週の計画テンプレートを毎回手動で作成している

**改善目標:**
- 週次レビューの時間を50%削減（3時間 → 1.5時間）
- データ集計を自動化
- レポートと来週の計画テンプレートを自動生成

## 🏗️ アーキテクチャ

### システム構成

```
Google スプレッドシート
├── 日次データ入力シート（手動入力）
├── 週次集計シート（自動集計）
├── レポートシート（週次レビュー用レポート）
└── 来週の計画シート（テンプレート生成）

Google Apps Script
├── 週次データ集計関数
├── レポート生成関数
└── 来週の計画テンプレート生成関数
```

### 主要コンポーネント

1. **日次データ入力シート**
   - 役割: 毎日の作業データを入力（記事数、収益、作業時間など）
   - 入力方法: 手動入力（または日記からコピペ）

2. **週次集計シート**
   - 役割: 週単位でデータを自動集計
   - 処理: GASで自動集計

3. **レポートシート**
   - 役割: 週次レビュー用のレポートを自動生成
   - 出力: 今週の成果、収益、改善点など

4. **来週の計画シート**
   - 役割: 来週の計画テンプレートを自動生成
   - 出力: 来週のネタ、スケジュール、目標など

## 📋 機能仕様

### 機能1: 週次データ集計

**概要:** 日次データ入力シートから週単位でデータを集計

**入力:**
- 日次データ入力シートのデータ（日付、記事数、収益、作業時間など）

**出力:**
- 週次集計シートに集計結果を出力
  - 今週の記事数（Note記事、WordPress記事、GASテンプレート）
  - 今週の収益（Note有料記事、WordPressアフィリエイト、GAS販売）
  - 今週の作業時間
  - 累計収益
  - 目標（8万円）までの残り

**処理フロー:**
1. 日次データ入力シートから今週のデータを取得
2. 記事数、収益、作業時間を集計
3. 累計収益を計算（前週までの累計 + 今週の収益）
4. 目標までの残りを計算（目標 - 累計収益）
5. 週次集計シートに出力

---

### 機能2: レポート生成

**概要:** 週次レビュー用のレポートを自動生成

**入力:**
- 週次集計シートのデータ
- 日次データ入力シートの詳細データ

**出力:**
- レポートシートに週次レビュー用のレポートを出力
  - 今週の成果サマリー
  - 収益の内訳
  - 作業時間の内訳
  - 改善点のテンプレート

**処理フロー:**
1. 週次集計シートから集計データを取得
2. 日次データ入力シートから詳細データを取得
3. レポート形式に整形
4. レポートシートに出力

---

### 機能3: 来週の計画テンプレート生成

**概要:** 来週の計画テンプレートを自動生成

**入力:**
- 今週のデータ（記事数、収益など）
- 目標（月次目標など）

**出力:**
- 来週の計画シートにテンプレートを出力
  - 来週のネタ（空欄）
  - 来週のスケジュール（曜日別）
  - 来週の目標（記事数、収益目標）

**処理フロー:**
1. 今週のデータから来週の目標を算出
2. 来週の計画テンプレートを生成
3. 来週の計画シートに出力

## 🔐 セキュリティ・制約事項

### セキュリティ対策
- スプレッドシートの共有設定を適切に設定
- 個人情報を含むデータは扱わない

### 制約事項
- GASの実行時間制限（6分）
- スプレッドシートの行数制限（500万行）

## 📝 設計思想・判断理由

### なぜスプレッドシートを使うか
- 手動入力が簡単
- データの可視化が容易
- GASとの連携が簡単

### なぜ週次集計を自動化するか
- 手動集計は時間がかかる
- ミスが発生しやすい
- 自動化により時間を削減できる
